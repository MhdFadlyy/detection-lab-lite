# detection-lab-lite

A laptop-friendly, Linux-first mini-SOC where every detection is code, tested in CI.

- **Docker only** — no Vagrant, no VM images.
- **Detection-as-code** — Sigma rules validated by replaying the real attack.
- **ATT&CK-mapped** — coverage matrix and Navigator layer generated from the rules.

See [ATT&CK coverage](coverage.md) for what's detected today, or the
[GitHub repo](https://github.com/USER/detection-lab-lite) to run it.
