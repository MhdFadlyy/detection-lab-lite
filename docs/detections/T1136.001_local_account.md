# T1136.001 — Local account created

| | |
|---|---|
| **ATT&CK** | [T1136.001](https://attack.mitre.org/techniques/T1136/001/) |
| **Tactic** | Persistence |
| **Severity** | medium |
| **Engine** | Wazuh FIM → rule `100313` |
| **Automated test** | ✅ attack replayed + alert asserted in CI |

## What it detects

Detects useradd/adduser execution — attacker creating a local account for persistence.

## Detection logic

```yaml
selection:
  Image|endswith:
  - /useradd
  - /adduser
condition: selection
```

Wazuh FIM (`syscheck`, inotify real-time) fires **rule `100313`** from [`detections/wazuh-native/0300-persistence.xml`](https://github.com/MhdFadlyy/detection-lab-lite/blob/main/detections/wazuh-native/0300-persistence.xml) (`<if_group>syscheck</if_group>` + a `file` regex).

## Attack scenario — `./lab attack T1136.001`

*Create a local account with useradd (persistence — not reverted; ./lab down clears it)*

```bash
userdel -rf dll_backdoor 2>/dev/null || true
useradd -m -s /bin/bash dll_backdoor
id dll_backdoor
```

`./lab verify T1136.001` then asserts the alert reached the indexer.

## Known false positives

- Provisioning scripts, package post-install hooks
