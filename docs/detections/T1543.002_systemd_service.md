# T1543.002 — systemd unit file created or modified

| | |
|---|---|
| **ATT&CK** | [T1543.002](https://attack.mitre.org/techniques/T1543/002/) |
| **Tactic** | Persistence, Privilege Escalation |
| **Severity** | medium |
| **Engine** | Wazuh FIM → rule `100311` |
| **Automated test** | ✅ attack replayed + alert asserted in CI |

## What it detects

Detects creation or modification of a unit file under /etc/systemd/system — service persistence.

## Detection logic

```yaml
selection:
  TargetFilename|startswith: /etc/systemd/system/
  TargetFilename|endswith: .service
condition: selection
```

Wazuh FIM (`syscheck`, inotify real-time) fires **rule `100311`** from [`detections/wazuh-native/0300-persistence.xml`](https://github.com/MhdFadlyy/detection-lab-lite/blob/main/detections/wazuh-native/0300-persistence.xml) (`<if_group>syscheck</if_group>` + a `file` regex).

## Attack scenario — `./lab attack T1543.002`

*Drop a malicious systemd .service unit (persistence — not reverted; ./lab down clears it)*

```bash
printf '[Unit]\nDescription=dll test\n[Service]\nExecStart=/usr/bin/id\n[Install]\nWantedBy=multi-user.target\n' > /etc/systemd/system/dll-evil.service
ls -l /etc/systemd/system/dll-evil.service
```

`./lab verify T1543.002` then asserts the alert reached the indexer.

## Known false positives

- Package installation, configuration management
